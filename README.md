# Anabolix

PS 01: Glitch Verse

A dark first-person puzzle adventure set in a decaying space where the player must find the exit while being hunted by a shifting, oppressive presence. As you progress through each sector, broken physics and environmental manipulation become your only tools. The deeper you go, the more you uncover the truth: the true enemy is not an external creature, but the self-doubt that has been haunting you all along.

## Story

You awaken in a dark, deteriorating space with one goal: find the exit.

As you navigate through the rooms, a shadowy entity blocks your path, alters the environment, and constantly tries to discourage you from moving forward. To progress, you must manipulate broken physics and solve puzzles across each sector.

In the end, you discover the entity was never an outside monster—it was your own self-doubt holding you back all along.

## Features

- Perspective: First-person puzzle-adventure
- Atmosphere: Dark, minimal, psychological tone
- Progression: 4 distinct puzzle levels
- Mechanics: 3 environment-altering abilities (Gravity, Time, Phase)
- Controls: Standard WASD + Mouse movement, number keys for abilities

## Gameplay Overview

Explore a fractured, hostile world where each room is a test of logic, timing, and perception. Use your abilities to reshape the environment and overcome obstacles that stand between you and escape.

## Controls

- W A S D: Move
- Mouse: Look / Aim
- 1 / 2 / 3: Use abilities (Gravity, Time, Phase)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/0ne-Code/Anabolix.git
   cd Anabolix
   ```

2. Open the project in Unity.

3. Use the Unity version compatible with the project configuration.

4. Let Unity import the project and dependencies.

5. Press Play to begin.
